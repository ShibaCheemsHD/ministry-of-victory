# Icon artwork credits

Game artwork depicts HELLDIVERS 2, owned by Arrowhead Game Studios and Sony Interactive Entertainment. This is an unofficial fan project. Repository software licenses do not transfer ownership of the game artwork.

- Medal, Common/Rare/Super Samples: War Monitor community asset collection, https://github.com/devpoole2907/Helldivers-Companion/tree/ea1f522f31c6bddcedb94935f4510c00d9c54c18/Helldivers%20Companion/Assets.xcassets.
- Terminids, Automatons, Illuminate and Super Earth faction emblems: helldivers-2/companion, https://github.com/helldivers-2/companion/tree/2acf503d66f3ca18fe223082ffd4f9c42a2b2b99/public/factions.
- Resupply, M-1000 Maxigun and Eagle Airstrike SVG recreations: nvigneux/Helldivers-2-Stratagems-icons-svg, https://github.com/nvigneux/Helldivers-2-Stratagems-icons-svg . Its README invites reuse in other projects.

Raster assets are resized to their display needs and encoded as lossless WebP. Shapes, aspect ratios and source palettes are retained. Embedded assets load with the page, without remote image requests. Exact source URLs are also stored beside each asset in src/game/icons.json.
